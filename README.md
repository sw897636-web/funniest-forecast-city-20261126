One line: the funniest weather forecast for a city that does not exist.

`main.ts` (Node 22, standard library only) writes the entry deterministically to `/output/entry.txt`:

> Weather for Umbraville: rain will fall upwards, so residents should wear hats and keep their puddles indoors.

Run it with `node main.ts`. The output is byte-identical on every run, with no network access.
